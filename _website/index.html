AgentTorrent

A dataset of the context and harness configuration of coding agents in engineered software projects on GitHub. It contains configuration artifacts for six tools, their imported files, agentic planning documents, and commits that credit the tools. The tools are Claude Code, GitHub Copilot, OpenAI Codex, Cursor, OpenCode and Gemini, which includes Antigravity, Google's successor to Gemini CLI.

Of the 40,901 engineered software projects in the sample, 10,944 contain a configuration artifact. In these projects, 1,281,628 commits credit one of the six tools and 72,527 credit one of 154 other tools. Compared with the earlier dataset, AgentTorrent adds OpenCode as the sixth tool, as well as plugins and LSP servers as mechanisms. It also adds the files that configuration artifacts import, the commits of other tools, the form in which each commit credits a tool, and agentic planning documents, which spec-driven development frameworks and the planning features of the tools write. Every heuristic cites the vendor documentation or the commits that it rests on. Still, a configuration artifact does not show that a tool is used, and a credit in a commit does not show who wrote the change. Until AgentTorrent 1.0.0 was renumbered from 2.0.0, this site offered its files with the dataset_version 2.0.0. The README of the release defines every column, and the changelog lists every change.

Visualizations

Interactive charts of which tools and mechanisms the repositories configure, how the tools co-occur, and when the repositories created their first configuration artifacts.

Configuration Mechanisms per Tool

Repositories with each mechanism, by the tool attributed to each configuration artifact. Files attributed to several tools count under each tool. Shared files such as AGENTS.md count in no tool column. The last column counts repositories with only shared configuration artifacts (No specific tool). Percentages use the repository count per tool. Column totals can exceed the overall repository count because repositories can configure several tools.

Tool Usage by Programming Language

The main programming languages of the repositories that configure each tool. No specific tool denotes the repositories with only shared configuration artifacts, such as AGENTS.md, .agents/skills or a root .mcp.json. Percentages are relative to the repository count per tool. Column totals can exceed the overall repository count because a repository can configure several tools.

Tool Co-Occurrence

Repositories that configure both tools in a pair. Percentages use the repository count of the less common tool.

Reference Network Between Context Files

Context files that only reference another file, by source and target category. Other covers files such as README.md and CONTRIBUTING.md.

Tool Usage Combinations (Exclusive Intersections)

Each bar counts the repositories that configure exactly its combination of tools, so each repository appears in one bar.

Distribution of Configuration Artifacts per Repository

Counts of context files, skills, and subagents per repository. For each mechanism, percentages use repositories with at least one configuration artifact of that mechanism.

Creation Order Sequences

Context file categories in the order that their earliest files were created in each repository. Creation dates follow the original commit, including before a file was renamed into a category. Curly braces group categories with earliest files created on the same day.

Creation of the Earliest Configuration Artifacts

The cumulative number of repositories by the month in which their earliest file of each kind was created, for five kinds of context file, for skills and subagents, and for planning documents. A file is dated by the commit that created it under whatever name it had then. Files created before 2023 are left out, because they were written for another purpose and only later renamed into a context file or named in a configuration, such as a development document that a repository renamed to claude.md and then to AGENTS.md. The Copilot Instructions line counts .github/copilot-instructions.md and .github/instructions/*.instructions.md.
